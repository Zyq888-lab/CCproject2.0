## 本轮发布审查接受的 P1

总裁已通过员工 A，但周期因员工 B 尚未确认而仍处于 `CALIBRATING` 时，所属 PD 仍可修改 A 的 KPI。A 的确认记录保持 `APPROVED`；随后 B 通过时，最终结果采用 A 的新分，A 无需重新确认。

根因是 `CalibrationService.adjustKpi` 只检查周期、任务和 PD 项目阶段权限，没有检查人员确认状态；`CalibrationMatrixPage` 在无退回人员时仍提供改分入口。2026-09-28 用户明确接受此风险并要求继续更新 PR；本次未修复，不代表该行为已通过业务验收。修复建议和优先级 P1 见 [TODOS](../../../TODOS.md)。
