# v2.14.2.0：周期指标明细导出

管理员进入“考核周期 → 监控”，点击“导出指标明细”可下载 Excel。每个指标一行，包含周期编码及名称、任务编号、员工工号及姓名、项目编码及名称、阶段、项目角色、考核类型、指标编号及名称、评价标准、权重、三种分数、评估人和任务状态。原“导出CSV”继续提供任务汇总。

导出沿用当前员工、项目、状态、审批节点筛选。多角色在同一单元格换行，工号保留前导零，权重以百分比显示，分数为数值。没有指标的任务不生成明细行；当前结果没有可导出的指标时禁用明细导出。

## 分数口径

- 原始评分：评估人的单项分，与监控“查看”明细一致。
- PD 校准分：PD 填写的单项覆盖分，未校准留空。
- 最终采用分：存在 PD 校准分时采用该分，否则采用原始评分；未评分留空，零分保留。

最终采用分是单项分数，不是员工综合总分，是否已确认或发布以系统页面为准。Excel 的“导出说明”工作表保留以上说明。

接口新增周期名称与按指标 ID 对应的校准分，复用原有任务评分查询。没有修改原始分、监控总分、审批规则或权限，没有新增数据库迁移。若校准分元数据加载不完整，明细导出会禁用并提示刷新，防止把未知校准分误认为未校准。
